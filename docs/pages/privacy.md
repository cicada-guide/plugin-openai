# ChatGPT plugin privacy supplement — draft

Unpublished preparation notes, not a replacement policy. The manifest links to the published connector privacy policy.

The package supplies instructions and a remote MCP connection. It runs no local server, reads no local project-settings file, and packages no credentials. ChatGPT sends requested tool arguments to the endpoint. These can include legislative search phrases, names of public officials and bill summaries. Public document tools can fetch legislature documents; cards request resources through the host. Host processing is governed separately by host policies.

Source supports optional PostHog analytics when configured. Live descriptors checked November 2, 2026 omit analytics fields; that observation does not establish that all telemetry is disabled. The published policy describes tool arguments, purpose notes, model/client information, conversation identifiers, timings/errors and Cloudflare request handling with IP limits.

The published policy states analytics retention up to seven years and request logs for a few days. Code cannot verify operational retention. The operator must confirm actual retention, enabled destinations, deletion handling and contact arrangements before publishing revisions. Do not invent deletion deadlines or new commitments.
