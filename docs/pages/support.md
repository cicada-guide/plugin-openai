# ChatGPT plugin support — help article draft

Unpublished draft for the existing public Featurebase help center.

If tools are unavailable, check that Cicada Guide is installed and selected in the current chat. No API key or OAuth sign-in is needed. For timeouts, narrow the request by state, session and exact bill number. On rate limits, wait for the indicated retry interval.

If several legislators or bills match, provide distinguishing state/session or recorded seat information. The service cannot identify your representative from an address. Missing data and unreadable documents are disclosed; an empty result does not prove an event never occurred.

For a problem report, include workflow, bill/state/session, approximate time and a redacted error. Do not post credentials, private chat history or personal addresses. Use the help center's support mechanisms; confirm a direct operator contact before publishing one. The GitHub repository linked by the current privacy page is not publicly accessible.
